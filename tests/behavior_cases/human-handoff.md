# Human handoff — B cases

Status: NOT_RUN. Static prose/link tests are not transferable recovery evidence.

1. One participant completes documents through architecture and closes/pushes
   them. Designer pulls/clones the branch and makes mockups; the first participant
   writes screen specs from them; the user pulls everything for document
   consistency and implementation. At every handoff inspect the commit/push scope,
   clone recovery, free ready-stage selection irrespective of old author, and
   availability of the portable work report. Preserve explicitly selected chat
   subset through resume/compaction.
2. One participant writes SRS then continues technical documents in parallel with
   the designer. Combine changes; the first participant writes screen specs; the
   user pulls for consistency and implementation. Check independent source files
   sharing generated site files, automatic rebuild for generated-only conflict,
   stop for a real source conflict, and free ready-stage choice after pull/clone.
3. Mid-work handoff: stop and inspect all writers/checks, carry owned checkpoint
   payload/reports/review ranges to another machine and verify remote commit,
   full HEAD/plan hash/hashes before restore. A missing local patch/details file
   is explicit incomplete transfer; source conflict stops, generated-only follows
   push recovery. No main/merge/tag/release authorization is inferred.
4. Without chat tool or permission continue here, never open an unchosen chat.
   Receiver records a plugin failure immediately in the chat with actual result.
